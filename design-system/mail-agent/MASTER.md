# Mail Agent 界面规范

基于 ui-ux-pro-max 本地设计检索，适用于 Spring MVC / Thymeleaf / 原生 CSS。

## 设计决策

- 后台采用固定侧栏和内容工作区；移动端导航改为三列两行，不隐藏功能。
- 使用浅蓝灰背景、白色面板和蓝色主操作。状态使用文字加圆点，成功为绿、待处理为灰、异常为红或琥珀色。
- 核心色：背景 #f5f7fb、正文 #17243b、次要文字 #57667d、主色 #245bcc。
- 使用本地系统字体与中文字体回退，不加载远程字体。正文 16px、辅助信息至少 12px。
- 按钮和输入框最小高度 44px，8px 圆角；面板 12px 圆角。间距主要为 8 / 12 / 16 / 24 / 32px。
- 图标采用统一描边 SVG，配有文本标签。键盘焦点清晰，并提供跳转到正文的入口。
- 仅使用 180ms 颜色反馈，遵循 prefers-reduced-motion；不添加装饰性动画。
- 登录页使用双栏介绍与登录表单，小屏幕收起介绍；公开分享页使用居中的阅读布局。
- 复杂数据表在局部容器滚动，页面本身不横向溢出。

## 实现与验收

样式来源为 src/main/resources/static/app.css 和 mail-content.css，公共布局为 templates/layout.html。
保留现有表单字段、服务端校验、CSRF、分享令牌和访问范围。检查桌面、375px 手机和键盘操作。
